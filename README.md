# Portfolio

A collection of my university coursework and personal software projects, built during my BSc (Hons) Software Engineering degree at Nottingham Trent University and in my own time.

## Projects

### [Final Year Project - Quantum Cryptography](./Final%20Year%20Project%20-%20Quantum%20Cryptography)
Simulated classical, quantum, and post-quantum cryptographic algorithms (RSA, BB84, Shor's, Grover's, Kyber) using Python and the Qiskit quantum simulator.
Originally developed on: Nottingham Trent University's internal Git server (Olympus) — at: https://olympus.ntu.ac.uk

### [Car Meets Webpage - Event Booking System](./Car%20Meets%20Webpage%20-%20Event%20Booking%20System)
Started as a static car-meets event site (HTML/CSS/JS), later rebuilt as a full database-driven booking platform using ASP.NET Core Razor Pages (C#) with user accounts, an "Attending list", ticket generation, and an admin dashboard.
Originally developed on: Nottingham Trent University's internal Git server (Olympus) — at: https://olympus.ntu.ac.uk

### [Time Tabling System](./Time%20Tabling%20System)
A C++ console application for managing university timetables, with separate Admin and Student interfaces and file-based data persistence.
Originally developed on: Nottingham Trent University's internal Git server (Olympus) — at: https://olympus.ntu.ac.uk

### [Screen Time Tracker](./Screen%20Time%20Tracker)
An Android app (Java) that tracks daily app usage, stores history locally with Room, and exports usage data to CSV.
Originally developed on: Nottingham Trent University's internal Git server (Olympus) — at: https://olympus.ntu.ac.uk

### [Data Breach Case Study](./Data%20Breach%20Case%20Study)
An Information Security coursework report analysing a real government data breach and designing a tailored Information Security Management System (ISMS), with a risk register and controls mapped to ISO/IEC 27001 Annex A.

### [Trading Bot](./Trading%20Bot)
A Telegram-integrated Python bot that generates trading signals using technical indicators such as VWAP.
Originally developed at: [ulas27/Bot](https://github.com/ulas27/Bot)

### [Truck Navigation App](./Truck%20Navigation%20App/truck-nav-main)
An early-stage navigation concept for HGV drivers, exploring route planning with truck-specific constraints.
Originally developed at: [emreulasinci/truck-nav](https://github.com/emreulasinci/truck-nav)

### [Store Website](./Store%20Website)
A practice website built for a family business, structured as a TypeScript monorepo.
Originally developed at: [ulas27/IK-Website](https://github.com/ulas27/IK-Website)
